# Виртуальный тур по объекту недвижимости · КТ3

Консольная Java-версия процедурного прототипа КТ2. Программа читает JSON, предлагает сопоставления панорам с помещениями, создаёт черновик и сцены, проверяет граф переходов и при успешной проверке записывает опубликованную версию тура в JSON. URL с доменом `example.invalid` используется для демонстрации.

## Сборка и запуск

Нужны JDK 17 или новее и Apache Maven 3.9. Maven загружает Gson при первой сборке. Команды выполняются из папки `src/java`.

```text
mvn clean package
java -jar target/virtual-tour.jar --input example_input.json --output result.json
```

Без параметров программа читает `example_input.json` и пишет в `result.json` в текущей папке. Оба файла используют UTF‑8. Ключ `--help` выводит подсказку.

## Демонстрационный пример

В `example_input.json` есть три помещения, три панорамы и переходы `1 → 2 → 3`. Ожидаемый вывод:

```text
Предложений помещений: 3
Создано сцен: 3; проверка: успешно
Опубликована версия 1: https://example.invalid/tours/1/v/1
Файл результата: result.json
```

В `result.json` ожидаются сопоставления `11 → 1` (3 балла), `12 → 2` и `13 → 3` (по 2 балла). У тура статус `published`, у первой сцены `is_start: true`, а результат проверки — `{"ok": true, "errors": [], "unreachable_scene_ids": []}`. При сравнении с КТ2 учитывайте, что `published_at` содержит фактическое время каждого запуска в UTC.

Если удалить переход из сцены 2 в сцену 3, проверка сообщит о недостижимой сцене. Программа завершится с кодом 2 и не запишет новый результат.

## Классы и алгоритмы

- `Panorama` задаёт общий тип панорамы. Подкласс `Hinted` использует подсказку оператора, `FromFile` — имя файла. Полученное имя используется и в сцене, и при сопоставлении.
- `RoomMatcher` применяет две реализации интерфейса `MatchingRule`: точное совпадение и совпадение по синониму. При равенстве лучших оценок сохраняются все кандидаты. При отсутствии совпадений панорама направляется на ручную проверку.
- `Tour` создаёт сцены и выпускает версию после проверки. `TourGraph` строит список смежности и обходом в ширину находит сцены, достижимые из старта.
- `List` хранит упорядоченные сущности, `Map` индексирует сцены и переходы графа, `Set` хранит синонимы и посещённые сцены.
- `Property` хранит связанного риелтора в записи `Realtor`. В JSON можно передать объект `realtor` с идентификатором `realtor_id`, именем `full_name` и контактом `contact`. Старые входные файлы без `realtor` поддерживаются. Сведения о риелторе относятся к входным данным объекта. Формат результата совпадает с форматом процедурной версии.
